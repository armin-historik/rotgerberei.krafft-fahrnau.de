# Rotgerberei – GitHub Pages

Repository für rotgerberei.krafft-fahrnau.de. Alle Dateien ins Stammverzeichnis laden. In Settings → Pages: Deploy from a branch, main, /(root). Unter Custom domain rotgerberei.krafft-fahrnau.de eintragen. DNS beim Domainanbieter: CNAME-Record `rotgerberei` auf `armin-historik.github.io` (sofern GitHub-Benutzername armin-historik unverändert). HTTPS nach DNS-Prüfung aktivieren.

Vor endgültiger Veröffentlichung: Quellenbeleg zu Krafft 1854 mit Archivsignatur ergänzen; Texte redaktionell prüfen. EN/FR folgen erst nach Abnahme der DE-Version.
